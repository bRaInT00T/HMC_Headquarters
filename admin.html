Commissioner Admin

Connect Yahoo (optional but recommended), set the draft order, and manage picks.

1. Yahoo Sync

If your league drafts inside Yahoo, connect it once and picks sync automatically — no manual transcription, no typos. Requires YAHOO_CLIENT_ID, YAHOO_CLIENT_SECRET, YAHOO_REDIRECT_URI, and YAHOO_LEAGUE_KEY set in Vercel (see README.md).

Connect Yahoo Account

2. Draft Date

Shown on the public draft board, and counted down to on the homepage. Time is optional — leave it blank if you've only locked in the day.

3. Draft Mode

Mock and Testing exist so the board can be wiped and re-run while you rehearse. Live is the real draft: once the draft date above is in the past, resetting the board is locked out — on the server as well as here, so a tab left open from yesterday can't wipe a draft in progress.

4. Draft Order Setup

Draft order is drawn from a hat each year. Yahoo sync backfills this automatically from round 1 — or set it by hand below before the draft starts. Drag a row by its handle to reorder.

5. Player Database

Powers the autocomplete in "Record a Pick Manually" below. Pulls the NFL player list from balldontlie's API into Supabase — run it once before draft day, and again if rosters change (trades, waivers). Takes a few minutes since the free API tier is rate-limited.

6. Keepers & Traded Picks

Set these before draft day. A keeper is recorded as that team's pick in the round the rules assign it (prior-season round, after any Bump Up), so it fills its cell on the board and the draft skips over it. A traded pick keeps its place in the snake order — only the team making it changes — matching the rule that the acquiring team gets an extra pick in that round and the original team loses theirs.

Add a Keeper

Traded Picks

Pick trades are a swap: each side gives up a pick, and the two must be from different rounds. Example — Quattro Formaggio trades its 10th rounder to Bad News Hilts for their 3rd rounder. The Firesale limit is enforced here: per round band (rounds 1–3, 4–7, and 8+), each team may trade away one pick and trade for one pick per season.

7. Record a Pick Manually

Fallback for leagues not drafting in Yahoo, or to fix a synced pick. Position and NFL Team narrow the player-name autocomplete, and fill in on their own once you pick a player from the list. Position lists our roster slots, not raw NFL positions — W/R/T spans WR, RB and TE, and DEF offers the 32 team defenses by name (individual defenders aren't draftable). The form opens on whichever pick is on the clock and advances in snake order after each save (stepping back on Undo). To correct an earlier pick, set Pick # to it — Round, Team and the recorded player load in, and saving overwrites that pick rather than appending a new one.
