Commissioner Admin

Connect Yahoo (optional but recommended), set the draft order, and manage picks.

1. Yahoo Sync

If your league drafts inside Yahoo, connect it once and picks sync automatically — no manual transcription, no typos. Requires YAHOO_CLIENT_ID, YAHOO_CLIENT_SECRET, YAHOO_REDIRECT_URI, and YAHOO_LEAGUE_KEY set in Vercel (see README.md).

Connect Yahoo Account

2. Draft Date

Shown on the public draft board, and counted down to on the homepage. Time is optional — leave it blank if you've only locked in the day.

3. Draft Order Setup

Draft order is drawn from a hat each year. Yahoo sync backfills this automatically from round 1 — or set it by hand below before the draft starts. Drag a row by its handle to reorder.

4. Player Database

Powers the autocomplete in "Record a Pick Manually" below. Pulls the NFL player list from balldontlie's API into Supabase — run it once before draft day, and again if rosters change (trades, waivers). Takes a few minutes since the free API tier is rate-limited.

5. Record a Pick Manually

Fallback for leagues not drafting in Yahoo, or to fix a synced pick. Position and NFL Team narrow the player-name autocomplete. Position lists our roster slots, not raw NFL positions — W/R/T spans WR, RB and TE, and DEF offers the 32 team defenses by name (individual defenders aren't draftable).
